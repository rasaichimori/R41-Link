How it works

Note map

Selected block

12481632

No lit pixels, so this block sends no note.

Point at a block to inspect it. Click or tap to keep it selected.

The display is 26×27 pixels, split into 117 blocks of 2×3. Each block is one MIDI note: 127 in the top-left corner, counting down row by row to 11 in the bottom-right.

Each pixel in a block has a value. A block’s velocity is the sum of its lit pixels, from 1 to 63. Empty blocks send no note.

A video exports one chord per frame across the range you choose, at your export frame rate. Tempo is written into the file and used to time each frame.
